## 开发协作约定

1. 每次只推进一个具体任务，先解释业务和设计，再由开发者编码。
2. 优先给思路、伪代码、方法职责；完整参考代码须由开发者明确提出。
3. 提交代码后先做 Code Review，再由开发者修改和测试。
4. 只有验收证据齐全才能标记完成；“已写代码”“编译通过”“接口验证通过”分别记录。
5. 已有代码逐步演进；新增依赖、数据库变更和接口契约调整在对应任务开始前说明。
6. 每个任务完成后更新 `progress.md`，每个阶段结束再复核该阶段全部验收项。
7. 文档不保存真实密码，不提交本地数据库数据，不以清表或重置 ID 作为日常测试方法。

## 本地运行提示

要求 JDK 21、MySQL 8 和 Maven Wrapper。Redis 在缓存阶段才需要。

本地 `src/main/resources/application.yaml` 已被 Git 忽略，包含数据源配置及 `mybatis-plus.configuration.map-underscore-to-camel-case: true`。仓库还没有无密码的示例配置和可复建 SQL，这属于后续任务，当前新克隆环境尚不能直接复现。

常用命令：

```bash
./mvnw compile
./mvnw spring-boot:run
```

修改 Java 文件后，当前项目需要重新编译并重启进程。浏览器访问仅适合简单 GET；写操作通过 Postman 测试。自动化测试将在独立测试库中运行，不能直接使用现有开发数据。
